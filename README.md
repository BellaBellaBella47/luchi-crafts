# Luchi Crafts

A warm, natural personal knitting portfolio for **luchi-crafts.co.uk**.

## Pages
- Home
- My Makes
- Knitting Journey
- About
- Gallery

This is deliberately a **personal portfolio, not a shop**. There are no prices, sales features, contact forms or business calls to action.

## Design
- Headings: EB Garamond
- Body/navigation: Inter
- Warm natural palette with cream, sage, clay and soft neutral tones
- Responsive for phones, tablets and desktops
- Placeholder artwork until real knitting photographs are added

## Future project updates
For each new make we can add a finished photograph, detail photograph, project name, dates, pattern/inspiration, yarn and needles, what was enjoyable or difficult, what was learned, and what to change next time.

## Deployment
The site is plain HTML/CSS/JavaScript and requires no build step.
